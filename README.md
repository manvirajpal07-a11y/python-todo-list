# Python To-Do List

A simple command-line To-Do List application built using Python.

## Features

- Add new tasks
- View all tasks
- Delete tasks
- Handles invalid task numbers
- Simple menu-driven interface

## Technologies Used

- Python 3

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python todo_list.py
```
